## 🎯 关键流程体验路线

### 1️⃣ 空间管理（5分钟）

**目的**：理解空间的概念和作用

**步骤**：
1. 访问：https://localhost:9007
2. 点击左侧菜单"空间管理"
3. 点击"新增空间"
   - 空间名称：`测试空间01`
   - 应用ID：`bkflow`
   - 平台URL：`https://localhost:9007`
   - 描述：`用于测试的空间`
4. 点击"确定"创建

**关键概念**：
- 空间 = 独立的工作区域
- 不同空间的数据相互隔离
- 每个空间可以有独立的权限配置

---

### 2️⃣ 流程模板创建（10分钟）

**目的**：创建一个简单的工作流模板

**步骤**：
1. 点击左侧菜单"流程管理"
2. 点击"新建流程"
3. 填写基本信息：
   - 流程名称：`测试流程-HTTP请求`
   - 所属空间：选择刚创建的空间
   - 描述：`测试HTTP请求节点`
4. 进入流程编辑器

**添加节点**：
1. 从左侧拖拽"HTTP请求"节点到画布
2. 配置节点：
   - 节点名称：`获取天气信息`
   - 请求方法：`GET`
   - URL：`http://localhost:8000/is_admin_user/`
   - 超时时间：`10`
3. 连接"开始"→"HTTP请求"→"结束"
4. 点击"保存"

**关键概念**：
- 流程 = 由多个节点组成的工作流
- 节点 = 执行具体任务的单元
- 连线 = 定义执行顺序

---

### 3️⃣ 任务执行（⭐ 核心体验）

**目的**：执行流程并查看结果

**步骤**：
1. 在流程列表中，找到刚创建的流程
2. 点击"执行"按钮
3. 选择执行方式：
   - 立即执行
   - 输入任务名称：`测试执行01`
4. 点击"确定"启动任务

**查看执行过程**：
1. 自动跳转到任务详情页面
2. 观察节点状态变化：
   - 🔵 准备中 → 🟡 执行中 → 🟢 成功 / 🔴 失败
3. 点击节点查看详细信息：
   - 输入参数
   - 输出结果
   - 执行日志

**任务操作**（可选）：
- ⏸️ 暂停任务
- ▶️ 继续任务
- 🔄 重试失败节点
- ⏹️ 终止任务

**关键概念**：
- 任务 = 流程模板的一次执行实例
- 每个任务有独立的执行记录
- 可以查看详细的执行日志

---

### 4️⃣ 任务列表管理（5分钟）

**目的**：查看和管理所有任务

**步骤**：
1. 点击左侧菜单"任务管理"或"调试任务"
2. 查看任务列表：
   - 任务ID
   - 任务名称
   - 执行状态
   - 创建时间
   - 执行时长
3. 使用过滤条件：
   - 按状态筛选：运行中、成功、失败
   - 按时间筛选
   - 按关键字搜索

**批量操作**：
- 批量删除任务
- 批量重试失败任务

## 🎓 学习要点

### 核心概念
1. **空间** - 隔离的工作区域
2. **流程模板** - 可重复使用的工作流定义
3. **任务** - 流程的执行实例
4. **节点** - 执行具体操作的单元

### 架构理解
```
用户界面 (Frontend 9007)
    ↓
Interface 模块 (8000)
    ↓ 创建任务
Engine 模块 (8001)
    ↓ 执行节点
返回结果
```

### 数据流
```
创建流程模板 → 保存到数据库
    ↓
点击执行 → Interface 创建任务记录
    ↓
Engine 接收任务 → 开始执行
    ↓
逐个执行节点 → 记录状态和日志
    ↓
完成 → 更新任务状态
```
