# 全局变量创建问题调试指南

## 问题描述

**操作**：在流程编辑器中创建全局变量，填写信息后点击"确认"
**现象**：只发送了校验接口，没有保存，抽屉不关闭
**预期**：变量应该被添加到流程模板中

---

## 调试步骤

### 步骤 1：检查前端错误

**打开浏览器开发者工具 (F12)**

#### Console 标签
```
清空日志 → 点击确认按钮 → 查看错误
```

**常见错误**：
- `Cannot read property 'xxx' of undefined` - 数据结构问题
- `Validation failed` - 表单验证失败
- `Network error` - 网络请求失败

#### Network 标签
```
清空请求 → 点击确认按钮 → 查看新请求
```

**预期请求**：
- ✅ `GET /api/template/variable/check_variable_key/` - 校验（已有）
- ❓ `PUT /api/template/1/` - 保存模板（缺失？）
- 或 `POST /api/template/1/save_draft/` - 保存草稿

---

## 可能的原因

### 原因 1：前端验证失败
**症状**：点击确认后没有任何请求
**原因**：必填字段未填写或格式不正确
**排查**：
- 检查所有字段是否都填写了
- 变量名是否符合规则（字母开头，不含特殊字符）
- 变量类型是否选择了

### 原因 2：前端 JavaScript 错误
**症状**：Console 有错误信息
**原因**：前端代码执行失败
**排查**：
- 查看 Console 的完整错误堆栈
- 可能是之前的 JS 错误影响了后续操作

### 原因 3：全局变量需要保存流程
**症状**：确认后抽屉关闭，但没有变量
**原因**：变量只是暂存在内存中，需要保存流程才会持久化
**排查**：
- 点击流程编辑器的"保存"按钮
- 查看变量是否出现在列表中

### 原因 4：前端逻辑问题
**症状**：确认按钮无响应
**原因**：按钮事件未正确绑定
**排查**：
- 在 Console 中查看是否有 Vue/React 相关错误
- 检查按钮是否 disabled

### 当前看到的请求
```
GET /api/template/variable/input/?space_id=2       - 获取输入变量类型
GET /api/template/variable/                        - 获取变量列表
POST /api/template/analysis_constants_ref/         - 分析变量引用
GET /api/template/variable/check_variable_key/     - 校验变量名 ✅
```

### 缺失的请求
```
PUT /api/template/1/                               - 更新模板 ❌
POST /api/template/1/save_draft/                   - 保存草稿 ❌
```

**结论**：确认按钮点击后，没有触发保存流程模板的请求。

## 解决方案

### 方案 A：检查并修复前端错误
1. 清除浏览器缓存
2. 刷新页面
3. 重新填写变量信息
4. 点击确认

### 方案 B：手动保存流程
1. 点击确认后（即使没反应）
2. 点击流程编辑器顶部的"保存"按钮
3. 查看变量是否出现

### 方案 C：直接在画布中添加变量
1. 不使用"新建变量"弹窗
2. 直接在流程编辑器左侧的变量面板操作
3. 或在节点配置中引用新变量

### 方案 D：跳过全局变量
1. 暂时不使用全局变量
2. 直接在节点中配置固定值
3. 先完成任务执行的体验
